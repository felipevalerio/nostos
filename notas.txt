SDL é uma biblioteca que fornece funções que se comunicam diretamente com as funções específicas das API de diferentes sistemas operacionais (Windows, Linux, MacOS etc...)
Criando uma abstração em cima dessas funções e se tornando uma biblioteca cross plataform.

SDL_CreateWindow -> para criar uma janela

    SDL_CreateWindow(
        const char* name,
        int largura,
        int altura,
        SDL_WindowFlags flags(SDL_WINDOW_RESIZABLE)
    );

SDL_CreateRenderer -> cria um contexto de renderização 2D para uma janela especificada

pitch é a largura da imagem/texture em bytes
framebuffer pode ser pensado como uma representação em memória da janela (pixels) em que pode-se fazer manipulações nos pixels e depois renderizar isso na janela.
